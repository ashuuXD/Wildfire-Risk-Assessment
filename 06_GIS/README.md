# 06_GIS

- `risk_maps/` -- interactive Folium HTML wildfire risk maps
  (`wildfire_risk_map.html`, `dashboard_risk_map.html`), generated by
  `04_Source_Code/risk_mapping.py`.
- `spread_maps/` -- interactive Folium HTML fire-spread simulation maps
  (`fire_spread_map.html`, `dashboard_spread_map.html`), generated by
  `04_Source_Code/fire_spread.py`.

Open any `.html` file directly in a browser, or view them embedded inside
the Streamlit dashboard (`07_Dashboard/app.py`).

If `folium` is not installed, these modules fall back to saving a CSV
table instead (`wildfire_risk_table.csv` / `fire_spread_table.csv`).
