# 02_Data

## Folder Layout
- `raw/` -- raw synthetic layer generated by `generate_demo_data.py`
  (`synthetic_raw_weekly.csv`), plus (empty by default) space for real
  downloaded FIRMS/weather/DEM files in Phase-II.
- `processed/` -- cleaned data, model-ready dataset, model comparison,
  explainability, risk predictions, and `eda_plots/` (all generated by
  running the pipeline / `run_demo.py`).
- `sample/` -- a small sampled CSV suitable for quickly inspecting the
  schema without loading the full dataset.
- `data_dictionary.csv` -- column-by-column description of the model-ready
  dataset (see also `PROJECT ROOT/08_Documentation/DATA_PIPELINE.md`).

## DEMO MODE Notice
All CSV files in this folder are generated by the synthetic demo pipeline
(`generate_demo_data.py` -> `preprocessing.py` -> `feature_engineering.py`).
No real NASA FIRMS, weather, or satellite data is included. Real-world
data integration is documented (not executed) in `data_loader.py`.

## Regenerating the Data
```
python 04_Source_Code/generate_demo_data.py
python 04_Source_Code/preprocessing.py
python 04_Source_Code/feature_engineering.py
```
or simply run the full pipeline from the project root:
```
python run_demo.py
```

## Data Source Plan (Real Data, Phase-II)
| Category | Source | Link |
|---|---|---|
| Historical fire | NASA FIRMS (MODIS/VIIRS) | https://firms.modaps.eosdis.nasa.gov/ |
| Weather | NASA POWER / IMD | https://power.larc.nasa.gov/ |
| Vegetation | Google Earth Engine (MODIS NDVI/NDMI, land cover) | https://earthengine.google.com/ |
| Terrain | Copernicus DEM GLO-30 | https://registry.opendata.aws/copernicus-dem/ |
