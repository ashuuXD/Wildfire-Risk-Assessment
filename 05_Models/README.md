# 05_Models

Trained model artifacts (`.joblib`) are generated by `04_Source_Code/train_models.py`
and saved here automatically -- they are not pre-shipped in the repository
so the project stays lightweight and always trains on your own machine's
current random seed / library versions.

Files generated after running the pipeline:
- `logistic_regression.joblib`, `logistic_regression_scaler.joblib`
- `random_forest.joblib`
- `gradient_boosting.joblib` (XGBoost if installed, else sklearn GradientBoostingClassifier)
- `training_metadata.json` -- split sizes, class balance, backend used
- `evaluation_detailed.json` -- full per-model metrics, confusion matrices, classification reports

Regenerate with:
```
python 04_Source_Code/train_models.py
python 04_Source_Code/evaluate_models.py
```
